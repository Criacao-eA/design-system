# Regras inegociáveis

## REGRAS INEGOCIÁVEIS DE MARCA

1. **Nunca escreva `ë-A`.** Em texto corrido é sempre `e-A` e `e-Auditoria`. O trema
   existe no *desenho* do logotipo, não na palavra.
2. **Palavra sozinha vira logotipo.** Quando o nome aparecer fora de uma oração —
   cabeçalho, rodapé, assinatura, selo, rótulo de coluna — use o logotipo, não a palavra.
3. **Sub-marca não carrega a marca-mãe.** Não existe lockup `Sub-marca | e-Auditoria`.
   Toda sub-marca é autossuficiente.
4. **Estas expressões nunca quebram linha** (envolver em `<span class="ea-nb">` ou usar
   `&nbsp;` entre as palavras): `e-Auditoria`, `Simples Nacional`, `Simples Híbrido`,
   `Lucro Real`, `Lucro Presumido`, `Reforma Tributária`.
5. **Iniciais maiúsculas mesmo sozinhas:** "o Simples", "a Reforma". São nomes próprios do
   domínio fiscal. Minúscula só quando for mesmo o adjetivo ("de forma simples").
6. **Marca-mãe fala em azul.** Quando o assunto é a e-Auditoria, a paleta é azul e no
   máximo lilás. Pink, laranja e magenta só quando o assunto for sub-marca que os tenha.
