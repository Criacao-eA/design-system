Set de vidro em SVG — alternativa vetorial ao render

ea-icon3d

Os ícones acima são render 3D (PNG, sem alfa recolorível, peso alto, licença de terceiro). Este set faz o mesmo trabalho visual em SVG puro: escala sem perder, troca de cor por token, pesa ~1,5 KB cada e não depende de banco de imagem. Use este set quando o ícone 3D entrar em produto, LP ou e-mail; guarde o render fotográfico para peça de campanha onde o realismo é o argumento.

Como é construído. Toda peça do set tem as mesmas cinco camadas, na mesma ordem: sombra de contato (elipse desfocada na base), corpo com degradê diagonal claro→escuro, face de topo mais clara para dar volume, realce especular branco na aresta que recebe a luz, e um fio ciano de 1,2–1,6px na borda — o mesmo acento de dados da marca. A luz vem sempre do canto superior esquerdo. Mantendo essas cinco camadas e essa direção de luz, qualquer ícone novo entra no set sem destoar.

Não misture os dois sets na mesma grade. Ícone de traço 2D e ícone de vidro têm pesos visuais muito diferentes; lado a lado, o 3D domina e o 2D parece inacabado. Escolha um por seção.
