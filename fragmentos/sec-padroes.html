Padrões gráficos

Marca Web Novo na v3

Os oito padrões da e-Auditoria foram reautorados de PNG para SVG de <pattern> tileável. Cada um pesa cerca de 1 KB, escala sem serrilhado e assume a cor do container por currentColor — o mesmo arquivo serve para fundo claro e escuro.

A regra que vale para todos

opacidade 0,05–0,15

Padrão é textura de fundo, nunca competidor do conteúdo.

Sobre fundo claro: opacidade 0,05 a 0,12. Sobre fundo escuro: 0,06 a 0,15. Fora dessa faixa o padrão vira ruído e derruba o contraste do texto.

0,04 — some
0,08 — certo
0,12 — limite
0,24 — errado

A opacidade fica no elemento do padrão, não no container. Se você baixar a opacidade do container, o texto desbota junto.

Não coloque padrão atrás de texto corrido, tabela ou gráfico. Padrão vai em faixa, cabeçalho de seção, rodapé, cartão vazio e área de respiro.

<!-- estrutura recomendada: padrão isolado numa camada própria -->
<section class="faixa">
  <div class="faixa__padrao" aria-hidden="true"></div>
  <div class="faixa__conteudo">...</div>
</section>

.faixa            { position: relative; isolation: isolate; }
.faixa__padrao    { position: absolute; inset: 0; z-index: 0; opacity: .08; }
.faixa__conteudo  { position: relative; z-index: 1; }

Como recolorir

currentColor · mask-image

Duas formas de entrega, com comportamentos diferentes. O SVG inline herda a cor do container. O data URI em CSS não herda — a cor está congelada dentro da string. Para recolorir em CSS, use mask-image em vez de background-image.

/* A) SVG inline: troque a cor do container e o padrão acompanha */
.faixa__padrao { color: var(--ea-navy); opacity: .08; }

/* B) CSS background: a cor vive dentro do data URI (%23050634) */
.faixa__padrao { background-image: url("data:image/svg+xml,..."); }

/* C) CSS recolorível: máscara + cor do container */
.faixa__padrao {
  background-color: currentColor;
  -webkit-mask-image: url("data:image/svg+xml,...");
          mask-image: url("data:image/svg+xml,...");
  -webkit-mask-repeat: repeat;
          mask-repeat: repeat;
  color: var(--ea-navy);
  opacity: .08;
}

Dentro de um data URI o # precisa virar %23, os < e > viram %3C e %3E, e os atributos usam aspas simples. Um # cru corta a string no ponto do fragmento e o fundo some sem erro no console.

Cor do padrão: navy #050634 sobre fundo claro; branco ou ciano #00FFEA sobre navy. Azul de UI #2F24FF só nos padrões densos, e só quando o padrão for o gesto principal da peça.

Um padrão por peça. Dois padrões na mesma tela cancelam um ao outro e a peça perde a marca em vez de ganhar.

O que não fazer

checklist
  • Padrão atrás de parágrafo, tabela ou gráfico. O contraste do texto cai e não há opacidade que salve.
  • Padrão em PNG. Os PNGs do brandbook estão em uma cor fixa, pesam 4–120 KB e serrilham em tela retina. Use o SVG.
  • Esticar o SVG com viewBox + preserveAspectRatio="none". O tile deforma. Deixe o SVG em width="100%" height="100%" sem viewBox: o pattern em userSpaceOnUse mantém o tile no tamanho real em px.
  • Opacidade no container em vez do padrão. Desbota o texto junto.
  • # sem escape dentro do data URI. Vira fragmento de URL, o fundo some e o console não reclama.
  • Repetir o mesmo id de pattern em dois SVGs inline da mesma página. O segundo herda o primeiro. Sufixe o id por instância.
  • Padrão sobre foto. Foto já tem textura; some as duas e vira sujeira.
